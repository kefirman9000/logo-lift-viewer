# Logo Lift Viewer

An Android image viewer for checking logos and stock images. Swipe through your images and keep each one near the top of the screen instead of the middle, at a height you choose.

## Features

- **Height slider** – sets how far down the screen the image sits (6–85%).
- **Size slider** – sets the image width.
- **Black or white background.**
- **Swipe** left/right, or use the volume buttons, to move between images.
- **Open folder** – shows every image in a folder, sorted by name, and reopens it next time.
- **Pick images** – choose a handful of images, or share images to Logo Lift from your gallery.
- Tap the image to hide the controls. Full screen, and the screen stays on.
- **Update** button – checks GitHub for a newer version and downloads it only if you say yes.

## Install

Download the latest `LogoLift-*.apk` from [Releases](../../releases/latest) on your phone and open it. Android will ask you to allow installs from your browser the first time.

Every push to `main` builds a new signed APK with GitHub Actions and publishes it as a release.
